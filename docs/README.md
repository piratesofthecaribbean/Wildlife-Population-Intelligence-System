## 📚 Documentation Index

1. **System Architecture:** End-to-end data pipelines, Computer Vision (YOLO), Bioacoustics (Librosa + BirdNET), and FastAPI REST routing.
2. **API Documentation:** Interactive documentation available at `/api/docs` or `/api/redoc`.
3. **Database Schema & Models:** SQLAlchemy ORM models for Surveys, Species, Habitats, Monitoring Devices, Detections, and Users.
4. **Role-Based Access Control (RBAC):** Administrator, Wildlife Researcher, Conservation Officer, and Ranger workflows.
5. **Deployment Guide:** Containerized Docker Compose and cloud deployment guides for Vercel and Render.
